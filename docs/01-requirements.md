# Requirements

## Objective

- **Decided**: Replace the two failing Vercel-backed profile cards with SVG files generated by code owned by `ayutaz`.
- **Decided**: Keep the profile readable when an API request, token, or scheduled run fails.
- **Decided**: Do not depend on `github-readme-stats`, npm packages, or PyPI packages.

## Functional requirements

- **Decided**: Generate `assets/github-stats.svg` and `assets/top-languages.svg`.
- **Decided**: Fetch every repository page returned by the GitHub GraphQL API instead of silently stopping after 100 repositories.
- **Decided**: Exclude forks, archived repositories, and private repositories by default.
- **Decided**: Allow the inclusion policy and explicit repository exclusions to be configured in `profile-stats.json`.
- **Decided**: Run on demand and once per day through GitHub Actions.
- **Decided**: Commit new assets only when their underlying data or renderer version changes.

## Non-functional requirements

- **Decided**: Runtime and tests use Python 3.13 or newer and only the Python standard library.
- **Decided**: Python discovery, environment creation, locking, tests, and generation run through `uv`.
- **Decided**: API or rendering failure must not replace the last known-good assets.
- **Decided**: Tokens and repository names from private API results must never be written to generated output or logs.
- **Decided**: All dynamic SVG text must be XML escaped and generated SVG must parse successfully before publication.

## Scope boundaries

- **Decided**: Version 1 reports repository portfolio metrics, not an imitation of the undocumented `github-readme-stats` rank.
- **Decided**: Version 1 does not publish private repository aggregates.
- **Proposed**: A later version may add opt-in contribution metrics after their visibility semantics are documented and tested.
- **Open**: Production activation requires a read-only `PROFILE_STATS_TOKEN` Actions secret and an explicit commit/push request.

## Supported toolchain

- Python: `>=3.13`
- Local default: `.python-version` selects Python 3.13.
- Project runner and lock manager: `uv`
- Third-party Python packages: none
